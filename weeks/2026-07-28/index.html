Coding session and the minimal agentic system

Hands-on coding followed by a Chapter 1 review

July 28, 2026

This week has two parts. We will begin with a 20–30 minute coding session, then review Chapter 1 of the Agent Systems Guide to connect the code with the model, tools, runtime, and agentic loop.

Session plan

  1. 20–30 min · Coding session Use the Orders Agent workshop materials for a short hands-on exercise.
  2. Review · The Minimal Agentic System Connect the code to the model, tools, runtime execution, context, and agentic loop.

Session materials

  • Orders Agent introduction HTML presentation · a short introduction to the workshop and its tools.
  • Workshop materials and setup Goals, environment notes, and the learning path for the hands-on session.
  • Orders Agent learner notebook Live coding material for the session; this is not a Week 3 assignment.
  • Orders Agent solution notebook Answer key for facilitators and learners who want a reference.

Coding session goals

  1. Register normal Python functions as agent tools.
  2. Use one tool to list orders, then two tools to inspect the latest order.
  3. Read Phoenix traces for model calls, tool calls, arguments, and token totals.

The workshop begins with a small simulated weather tool before moving to the Orders Agent. It uses synthetic classroom data, so learners can inspect the traces safely.

Chapter 1 review

We will use the coding session to review the smallest useful agentic system: a model, tools, and a runtime-controlled loop. The runtime maintains context, calls the model, executes tool requests, returns results, and decides whether the loop should continue or terminate.

Reading assignment

  • Claude Code — How Claude Code works A product-level map of models, tools, the agentic loop, context, and the surrounding harness. Use it to review the chapter and see how the same ideas appear in a coding agent.
