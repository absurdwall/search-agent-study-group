Week 3

Build an Orders Agent and read Phoenix traces

July 28, 2026 · Search Agent Study Group

Materials

  • Workshop materials and setup Goals, environment notes, and the learning path for the session.
  • Orders Agent learner notebook Build the Agent, call its tools, and answer the numbered Phoenix concept checks.
  • Orders Agent solution notebook Answer key for facilitators and learners who want a reference.

Goals

  1. Register normal Python functions as Agent tools.
  2. Use one tool to list orders, then two tools to inspect the latest order.
  3. Read Phoenix traces for model calls, tool calls, arguments, and token totals.

Session flow

We start with a tiny simulated weather tool, then build the Orders Agent in small steps. The data is synthetic classroom data, so everyone can explore the traces safely.
