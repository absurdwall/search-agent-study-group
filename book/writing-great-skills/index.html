Study group guide · Chapter 4 Planned

Writing Great Skills

A planned chapter on turning a useful method into reusable guidance that an agent can discover, follow, and verify.

Planned scope

This chapter will examine when a Skill is the right abstraction; how its name and description affect discovery; how to separate ordered steps from reference material; how to write checkable completion criteria; and how progressive disclosure keeps the main SKILL.md focused while still making deeper resources available.

We will also need examples and a validation strategy before this chapter becomes a full authoring guide. The chapter number may change as the book develops.

Starting resources

These are reference-only planning materials. The source spine and teardown examples still require editorial confirmation before drafting. See the editorial reference packet for the frozen artifacts and open decisions.

  • OpenAI — Build skills Current official product guidance for Skill structure, discovery, progressive disclosure, supporting resources, and testing.
  • Agent Skills — Overview and Specification The open structural reference for SKILL.md, optional scripts, references, assets, metadata, progressive disclosure, and validation.
  • Matt Pocock — Writing for Agents A practitioner perspective on invocation, descriptions, information hierarchy, completion criteria, and progressive disclosure. Treat its recommendations as a point of view, not a specification.
  • OpenAI Gmail Skill — frozen teaching candidate The proposed main teardown for discovery boundaries, routed references, stop conditions, eval definitions, and maintenance tradeoffs. This recommendation has not yet been approved.
  • Superpowers — systematic-debugging A proposed short contrast for strong workflow structure and the risks of over-prescriptive artifact-specific doctrine.
