Study group guide · Chapter 4 Planned

Writing Great Skills

A planned chapter on turning a useful method into reusable guidance that an agent can discover, follow, and verify.

Planned scope

This chapter will examine when a Skill is the right abstraction; how its name and description affect discovery; how to separate ordered steps from reference material; how to write checkable completion criteria; and how progressive disclosure keeps the main SKILL.md focused while still making deeper resources available.

We will also need examples and a validation strategy before this chapter becomes a full authoring guide. The chapter number may change as the book develops.

Starting resources

  • Matt Pocock — Writing Great Skills The primary practitioner resource for this chapter: invocation, descriptions, information hierarchy, completion criteria, and progressive disclosure. Its recommendations are a strong point of view to evaluate, not the Agent Skills specification itself.
  • Agent Skills — Overview and Specification The open structural reference for SKILL.md, optional scripts, references, assets, metadata, progressive disclosure, and validation.
  • Anthropic — The new rules of context engineering for Claude 5 generation models Supporting perspective on keeping Skills lightweight, avoiding overconstraint, and moving detailed guidance behind progressive disclosure.
