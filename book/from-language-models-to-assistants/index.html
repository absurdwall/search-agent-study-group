Study group guide · Chapter 0 Planned

From Language Models to Assistants

A planned foundations chapter on language models, assistant behavior, and the structured interfaces that let an application work with a model.

Planned scope

This chapter will introduce language models and LLMs; tokens and tokenization; autoregressive next-token prediction; BERT- versus GPT-style models for beginners; pretraining, training, fine-tuning, and post-training; prompted completion and question answering; base versus instruction-following assistants; and structured API input and output, JSON schemas, tool-call output, and constrained structured generation.
